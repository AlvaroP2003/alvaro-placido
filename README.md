# Personal Portfolio 🚀

Welcome to my personal portfolio website!  
This project showcases my work, skills, and journey as a developer and creative thinker.

---

## ✨ About

This portfolio is designed to be a simple yet dynamic platform where visitors can explore:
- My featured projects
- Skills and technologies I work with
- A bit about me and my journey
- How to get in touch

The goal is to create a visually engaging and interactive experience that feels personal, modern, and authentic.

---

## 🛠️ Built With

- **React.js** — for component-based UI
- **Vite** — for fast development and builds
- **HTML5 & CSS3** — for structure and styling
- **JavaScript (ES6+)** — for interactions and animations
- **Framer Motion** *(optional)* — for smooth animations
- **Custom Hooks and Refs** — for effects like image tilt

---

## 📸 Features

- Responsive design (mobile, tablet, desktop)
- Smooth scroll and subtle animations
- Dynamic project showcase
- Interactive elements (e.g., image tilting based on mouse movement)
- Light and clean code structure
